# Cats - многостраничный сайт о котах

- Учебный статический сайт с тёмной темой, с шрифтом из Minecraft.  
> Название шрифта Monocraft.
- На каждой странице в блоке `main` отображается своя картинка.

## Страницы сайта

| Файл | Кот |
|------|---------------------|
| `index.html` | Floppa (главная)
| `komaru.html` | Komaru |
| `lord.html` | Lord |
| `maxwell.html` | Maxwell |
| `kotNaYlitche.html` | Street cat |
| `creator.html` | Cosdatel |

## Возможности

- Единый `header` и `footer` на всех страницах.
- Подключение кастомного шрифта `Monocraft` через `@font-face`.
