# Cats

- Учебный проект про котов

## Страницы сайта

| Файл | Кот |
|------|---------------------|
| `index.html` | Floppa (главная)
| `komaru.html` | Komaru |
| `lord.html` | Lord |
| `maxwell.html` | Maxwell |
| `chmona.html` | Chmona |
| `creator.html` | Cosdatel |

## Возможности

- Единый `header` и `footer` на всех страницах.
- Кастомный шрифт `Monocraft`.

## Технологии

- HTML5
- CSS3
